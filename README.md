# 楓之谷打王紀錄器 (MapleStory Boss Record)

一個基於 Python 的簡易工具，用於記錄與管理《新楓之谷》角色的 BOSS 通關時間、攻略難度、BUFF 使用狀態及相關角色資訊，並自動匯出儲存至 Excel 表格中。

更新至遊戲版本：V282 版本
---

## 🌟 功能特點

* **角色資料管理**：支援輸入角色名稱並快速取得現有打王狀態。
* **詳細通關紀錄**：可記錄攻略的 BOSS 名稱、難度、通關時間。
* **自訂備註**：提供自由填寫欄位，方便記錄特殊狀況。
* **Excel 自動存檔**：所有紀錄自動整合寫入 `BOSS.xlsm`，方便後續分析與追蹤。

---

## 🛠️ 環境需求與安裝步驟

在開始執行前，請確保你的電腦已安裝 **Python 3.x**。

### 1. 複製專案 (Clone)

```bash
git clone [https://github.com/LJBen/maplestory_recordBOSS.git](https://github.com/LJBen/maplestory_recordBOSS.git)
cd maplestory_recordBOSS

```

### 2. 安裝依賴套件

執行以下指令安裝專案所需的 Python 套件：

```bash
pip install -r requirements.txt

```



## 🚀 使用說明

只需要執行主程式 `main.py` 即可開始：

```bash
python main.py

```

### 🎯 操作流程

1. **輸入角色資訊**：輸入欲記錄的角色名稱。
2. **核對狀態**：確認並查閱目前資料庫中的角色與打王狀態是否符合。
3. **填寫通關紀錄**：
* 選擇或輸入攻略的 **BOSS 名稱** 與 **難度**（如：普通、極限、等）。
* 輸入 **通關時間**。
* 勾選是否使用 **秘笈 BUFF** 等增益效果。
* 填寫 **備註欄位**（可選）。

4. **完成存檔**：確認送出後，資料將自動寫入並更新至 `BOSS.xlsm`。
